# Веб-мессенджер

Веб-мессенджер в привычном его понимании - сделан на ванильном js c typescript, с использованием handlebars и scss

Реализован Block компонент для реактивного обновления, baseFetch обертка над XMLHttpRequest для правильной обработки
запросов

Так же использован eslint, prettier, stylelint для правильного форматирования кода и поддержки единой стилистики

Реализованы:
-Различные вспомогательные сервисы для разделения логики
-Доработан API для работы с запросами
-Правильный роутинг
-Различные утилиты для упрощения работы с данными
-Добавлены запросы на все страницы
-Авторизация, регистрация в приложении
-Страница профиля с редактированием основной информации, сменой пароля и аватара
-Страница чатов с подключением по Websocket протоколу для обмена сообщениями в реальном времени

Настроен прекоммит с помощью husky для поддержки стилистики кода и прохождения тестов перед коммитом

## Тест

Для unit-тестирования роутера, модуля для отправки запросов и компоненты была использована библиотека Jest

Чтобы запустить тесты необходимо прописать в терминале npm run test

## Установка

Установить зависимости проекта: `npm install`

Собрать проект: `npm run build`

Запустить проект со сборкой: `npm run start`
